AI 비서 설치 키트 — 테스트 확인 요청
====================================================================

설치해 보시고 아래 항목만 알려주시면 됩니다.
막히면 그 지점에서 멈추고, 화면을 캡처해 주세요.


■ 먼저 알려주실 것
--------------------------------------------------------------------
  1. 운영체제        Windows 10 / Windows 11 / macOS
  2. 계정 권한       관리자 계정인가요, 일반 계정인가요?
                     ※ 일반 계정 테스트가 특히 중요합니다
  3. 회사 PC 여부    회사에서 관리하는 PC면 알려주세요


■ 설치 과정 (윈도우)
--------------------------------------------------------------------
  1) install-windows.bat 을 더블클릭

     [확인] 파란 경고창(Windows의 PC 보호)이 뜨나요?
            → 뜨면 '추가 정보' → '실행'
     [확인] 검은 창의 한글이 깨지지 않고 제대로 보이나요?   ★중요

  2) 어떤 AI를 쓸지 묻는 화면

     [확인] 선택지가 읽을 수 있게 나오나요?
     → 그냥 Enter (1번 Claude Code, 유료 계정 필요)

  3) 설치 진행

     [확인] 중간에 빨간 글씨나 오류가 뜨나요? 뜨면 그대로 캡처
     [확인] 설치가 끝까지 갔나요? 몇 분 걸렸나요?

  4) 창을 완전히 닫고, 새로 명령 프롬프트를 엽니다

     [확인] gemini  라고 치면 실행되나요?
            (claude 를 골랐다면 claude)


■ 설치 과정 (맥)
--------------------------------------------------------------------
  1) install-mac.command 를 더블클릭

     [확인] "확인되지 않은 개발자" 경고가 뜨나요?
            → 뜨면 파일 우클릭 → 열기 → 열기

  2~4) 윈도우와 동일하게 확인


■ 알려주시면 좋은 것
--------------------------------------------------------------------
  · 어느 단계에서 헷갈렸는지 (설명이 부족한 부분)
  · 안내문에 없는데 직접 찾아봐야 했던 것
  · 전체적으로 몇 분 걸렸는지


■ 참고
--------------------------------------------------------------------
  · Gemini CLI 는 2026-06-18 부터 API 키가 필요합니다(구글 계정 로그인 불가).
  · Claude Code 는 유료 계정(Pro/Max)이 있어야 로그인됩니다.
  · 설치되는 것은 공식 배포판이며, 이 키트는 설치 명령을 대신 실행해
    주는 역할만 합니다.
