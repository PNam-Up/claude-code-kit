# 내 PC에 AI 비서 심기 — macOS

터미널에서 대화하듯 명령하면 **파일 정리 / 자동화 / 문서 작성 / 코딩**까지
대신 해주는 AI 비서(Claude Code)를 설치합니다.

## 먼저 확인하세요

**유료 Claude 계정(Pro / Max)이 필요합니다.** 무료 claude.ai 채팅 플랜으로는 작동하지 않습니다.
계정은 **본인 것**을 사용합니다. 이 키트는 공식 설치 명령을 대신 실행해 줄 뿐입니다.

---

## 설치

1. **`install-mac.command`** 를 **더블클릭**
2. "확인되지 않은 개발자" 경고가 뜨면 -> 파일 **우클릭 > 열기 > 열기**
3. 설치가 끝나면 로그인 창이 자동으로 열립니다
4. 브라우저에서 Claude 계정으로 로그인

## 잘 안 될 때

| 증상 | 해결 |
|---|---|
| `claude` 명령을 못 찾음 | **터미널을 완전히 종료 후 다시 열기.** 설치한 그 창에서는 인식되지 않습니다 |
| 로그인이 거부됨 | 무료 플랜입니다. Pro/Max 구독이 필요합니다 |
| 회사 PC에서 차단됨 | 보안 정책 문제. IT 담당자 문의 필요 |

**연결 해제**: `launchctl unload ~/Library/LaunchAgents/com.claudekit.telegram-bridge.plist`
토큰까지 지우려면 `~/.claude-telegram-bridge` 폴더를 삭제하세요.

---

## 텔레그램으로 원격 조종 (선택)

설치가 끝나면 **봇 토큰 입력**을 물어봅니다. 연결하면 폰에서 메시지를 보내
집에 있는 PC의 AI 비서에게 일을 시킬 수 있습니다. 건너뛰어도 정상 작동합니다.

1. 텔레그램에서 **@BotFather** 검색 -> 대화 시작
2. `/newbot` 입력 -> 이름/아이디 정하기
3. 받은 토큰(`123456:AAE...`)을 설치기에 붙여넣기
4. 만든 봇에게 **아무 메시지나 보내기** -> 설치기가 사용자를 자동 인식합니다

> ### 연결 전에 꼭 읽으세요
> 텔레그램으로 이 PC의 **파일을 읽고 쓰고 명령을 실행**할 수 있게 됩니다.
> 본인 계정에서 온 메시지만 처리하지만, **봇 토큰이 유출되면 남이 내 PC를 조종할 수 있습니다.**
> 토큰은 비밀번호처럼 다루세요. 회사 PC라면 보안 정책을 먼저 확인하세요.

## 쓰는 법

터미널을 **새로 열고**, 정리하고 싶은 폴더로 이동한 뒤 `claude` 를 입력합니다.

```
cd ~/Desktop/내폴더
claude
```

그다음엔 그냥 한국어로 말을 걸면 됩니다.

```
이 폴더에 있는 엑셀 파일들 요약해서 표로 정리해줘
```

> **어느 폴더에서 실행하는지가 중요합니다.** 실행한 폴더를 기준으로 파일을 읽고 씁니다.
